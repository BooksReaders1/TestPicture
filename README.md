# 漫画查看器

一个简洁的在线漫画阅读工具，提供流畅的阅读体验。

## 功能特点

- 📱 响应式设计，支持移动端和桌面端
- 🖼️ 高清图片渲染
- 📥 支持下载功能
- 🎯 悬浮菜单，便捷操作
- ⚡ 懒加载优化，提升加载速度

## 使用方法

1. 在 URL 中添加参数 `?id=漫画ID` 访问特定漫画
2. 使用悬浮按钮打开侧边菜单
3. 支持页面切换和浏览

## 技术栈

- HTML5 / CSS3
- JavaScript (ES6+)
- Canvas 图像渲染
- JSZip (压缩/解压)
- Blueimp MD5

## 本地运行

直接通过浏览器打开 `index.html` 文件即可使用。
